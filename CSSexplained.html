CSS Explained

CSS (abbreviation of Cascading Style Sheets) is the language used to style the presentation of websites made in HTML.

How CSS Works

  • To link CSS to an HTML document the <link> tag is used
  • CSS defines rules for how HTML elements are displayed
  • CSS can be used to:
    • Change the color, size, and font of text
    • Can also affect the layout of of a webpage
    • Can also be used to create interactive elements such buttons that change color when the mouse is hovering over it
      • Try hovering your mouse over the navigation bar at the bottom of the page for example
