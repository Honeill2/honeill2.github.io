HTML Explained

HTML (HyperText Markup Language) is the standard markup language for creating web pages. In this page I will describe HTML and aspects of it such as it's elements and attributes, the versions of it over the years, and how it could end up in the future.

HTML Elements

  • HTML has multiple elements that are used to enclose, wrap or make part of the content appear a certain way for example using < b> would make a text appear bold

  • An element can also have other embedded elements inside other HTML elements.

    • For example if I type < b > < i > < small > example text < /small > < /i > < /bold> (Without the spaces) I would get: example text

  • Elements can also be used to make ordered < ol > lists. and unordered < ul > lists.

    • This entire section is made as an unordered list for example
  • There are also void elements which cannot have other elements embedded inside them or have end tags.

HTML Attributes

  • HTML attributes often provide information on how the element and defines the element's behavior.

  • Attributes can also be used to change the appearance of the and functionality of an element.

  • HTML attributes also can only be in the opening tag of an HTML element. If it was put in somewhere like the middle of the element, it would not be valid.

HTML Versions

Over the years there were many versions of HTML, each one introducing new features and improvements.

Version Year Notes
HTML 1.0 1993 HTML 1.0 was fairly bare bones compared to how it is nowadays with it mainly being focused on document structure.
HTML 2.0 1995 HTML 2.0 was released in 1995 and added support for people to create more responsive websites.
HTML 3.2 1997 Built upon 2.0 and enhanced support for tables and list formatting while also adding support for image maps, applets, and style sheets.
HTML 4.01 1999 An updated version of HTML 4.0 that which mainly fixed errors, but also added attributes being able to use colons and underscores. Also would include the features introduced into base 4.0 such as: the ability to separate structure and presentation, the Fieldset element which would help form controls be grouped together,
XHTML 1.0 2000 A version of HTML that combined XML elements, and was a lot more strict than HTML
HTML5 2008 The current version of HTML, that was developed by WHATWG after the release of XHTML, and W3C briefly stopping support on basic HTML, would later be reccommended by W3C in 2014.
