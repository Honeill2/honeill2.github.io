Key Concepts

In this section I will go over seven concepts and terms that I go in depth with in this project

Term Definition
HTML HTML (HyperText Markup Language) is the standard markup language for creating web pages
CSS CSS (abbreviation of Cascading Style Sheets) is the language used to style the presentation of websites made in HTML.
HTML Elements Parts of HTML that are used to structure code for a webpage
HTML Attributes Properties that are embedded inside of HTML elements to give additional instructions on the layout, behavior and function of the element
CSS Selectors CSS Selectors target specific HTML elements, and are primarily used to apply styles to the elements.
Flexbox Flexbox is a layout model for arranging items in a container
